# CSS Box Model Demonstration

This project is a simple visualization of the CSS Box Model created using HTML and CSS. It demonstrates the four main components of the box model: **Margin**, **Border**, **Padding**, and **Content**. The nested box structure helps beginners understand how spacing and layout work in web development.

## Features

* Visual representation of the CSS Box Model
* Clearly labeled Margin, Border, Padding, and Content areas
* Nested box structure for better understanding
* Color-coded sections for easy identification
* Beginner-friendly design

## Technologies Used

* HTML
* CSS



## Components Demonstrated

The project illustrates the four layers of the CSS Box Model:

1. **Margin** – Space outside the border.
2. **Border** – Surrounds the padding and content.
3. **Padding** – Space between the content and border.
4. **Content** – The actual content area inside the element.

These components are visually displayed using nested containers and labels.

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
